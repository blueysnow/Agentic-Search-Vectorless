1. In `src/utils/json_utils.py`, add a helper function `_fix_latex_backslashes(json_content: str) -> str` that uses the regex:
   ```python
   re.sub(r'\\(?!["\\/bfnrtu])', r'\\\\', json_content)
   ```
   This replaces single backslashes NOT followed by valid JSON escape characters (`"`, `\`, `/`, `b`, `f`, `n`, `r`, `t`, `u`) with double backslashes. This converts LaTeX `\frac` into `\\frac` which is valid JSON.

2. Insert the LaTeX backslash fix into the `extract_json()` fallback chain. The new flow should be:
   - Try `json.loads(json_content)` (existing, line 50)
   - If fails: apply Python literal cleanup (None->null, True->true, False->false) (existing, lines 55-57)
   - Try `json.loads(json_content)` (existing, line 59)
   - If fails: try trailing comma removal (existing, line 63)
   - If STILL fails: apply `_fix_latex_backslashes()` to the ORIGINAL extracted json_content (before Python literal cleanup) and try `json.loads()` on the result
   - If that also fails: apply BOTH Python literal cleanup AND `_fix_latex_backslashes()` together and try one final time
   - Only return None if ALL attempts fail

   IMPORTANT: Apply `_fix_latex_backslashes` to the original extracted content, not to the Python-literal-cleaned version. This ensures the regex operates on the most pristine version of the string. The combined attempt handles the edge case where BOTH issues exist.

  <name>Task 2: Create math_extractor.py module and add has_math to Page model</name>
  <files>src/ingestion/math_extractor.py, tests/test_math_extractor.py, src/models/page.py</files>
  <action>
1. Create `src/ingestion/math_extractor.py` as a pure-function module with NO side effects, NO config imports, NO database imports. Include `from __future__ import annotations` at the top (per project convention).

   **Functions to implement:**

   `has_math(text: str) -> bool`:
   - Returns True if text contains any LaTeX math delimiters
   - Check for: inline math (`$...$` but not `$$`), block math (`$$...$$`), and `\begin{equation|align|gather|multline}` environments
   - Return False for empty string or None

   `detect_math_regions(text: str) -> dict`:
   - Returns a dict with keys: `has_math` (bool), `inline_count` (int), `block_count` (int), `equation_env_count` (int)
   - Counts non-overlapping matches for each pattern type

   **Regex patterns (compile at module level):**
   - Inline math: `(?<!\$)\$(?!\$)(.+?)(?<!\$)\$(?!\$)` with `re.DOTALL` -- uses negative lookbehind/ahead to avoid matching `$$` as two inline delimiters
   - Block math: `\$\$(.+?)\$\$` with `re.DOTALL`
   - Equation environments: `\\begin\{(equation|align|gather|multline)\*?\}`

   **IMPORTANT design notes:**
   - This module detects LaTeX delimiters in text that has ALREADY been processed (LLM output, LaTeX source). It does NOT attempt to find math in raw PDF output where no delimiters exist.
   - Keep it stateless and pure -- no logging, no side effects, no external dependencies beyond `re` stdlib.
   - Match the inline math regex AFTER the block math regex to avoid counting block math delimiters as inline.

2. Create `tests/test_math_extractor.py` with comprehensive unit tests:

   ```python
   from src.ingestion.math_extractor import has_math, detect_math_regions

   # --- has_math tests ---
   def test_has_math_inline():
       assert has_math("The formula is $x^2 + y^2 = r^2$ in polar form.") is True

   def test_has_math_block():
       assert has_math("$$\\frac{d}{dx}\\sin(x) = \\cos(x)$$") is True

   def test_has_math_begin_equation():
       assert has_math("\\begin{equation} E = mc^2 \\end{equation}") is True

   def test_has_math_begin_align():
       assert has_math("\\begin{align*} a &= b \\\\ c &= d \\end{align*}") is True

   def test_has_math_false_on_plain_text():
       assert has_math("This is plain Korean text without any math.") is False

   def test_has_math_false_on_empty():
       assert has_math("") is False

   def test_has_math_false_on_raw_pdf_garbled():
       assert has_math("f(x) = \ufffd\ufffd + \ufffd\ufffd") is False

   def test_has_math_false_on_currency():
       # Single dollar signs without math content pattern
       assert has_math("The price is 50 dollars.") is False

   def test_has_math_inline_does_not_match_block():
       # $$ should NOT be detected as two inline $ matches
       assert has_math("$$x^2$$") is True  # detected as block math
       result = detect_math_regions("$$x^2$$")
       assert result["block_count"] == 1
       assert result["inline_count"] == 0

   # --- detect_math_regions tests ---
   def test_detect_math_regions_mixed():
       text = "Solve $a + b = c$ and $x^2 = 4$. Also $$\\int_0^1 f(x) dx = 1$$."
       result = detect_math_regions(text)
       assert result["has_math"] is True
       assert result["inline_count"] == 2
       assert result["block_count"] == 1
       assert result["equation_env_count"] == 0

   def test_detect_math_regions_equation_env():
       text = "\\begin{equation} a = b \\end{equation} and \\begin{align} c = d \\end{align}"
       result = detect_math_regions(text)
       assert result["equation_env_count"] == 2

   def test_detect_math_regions_no_math():
       result = detect_math_regions("Plain text with no math at all.")
       assert result["has_math"] is False
       assert result["inline_count"] == 0
       assert result["block_count"] == 0
       assert result["equation_env_count"] == 0
   ```
